# Flow Runs Endpoint Examples

This document provides examples of how to use the flow runs endpoints to retrieve prompts and responses.

## Available Endpoints

### 1. GET `/api/flow-runs` - Get all flow runs
Retrieves all flow runs with their prompts and responses.

**Example Request:**
```bash
curl -X GET "https://deepseek-agent.alghamdimo89.workers.dev/api/flow-runs"
```

**Example Response:**
```json
[
  {
    "id": "flow_run_1772067089928_4t7ymzz5t",
    "flow_id": "test-dynamic-output",
    "conversation_id": "6b9a072d4a88f0b1a639dcd9af8356960e3170910a1dd324c35def6376d10dcf",
    "step_id": "test-step-3",
    "input_prompt": "Execute flow: test-dynamic-output",
    "output_response": "{\"sql\": \"UPDATE flow_steps SET step_type = 'hello' WHERE id = 'test-step-3';\"}",
    "status": "completed",
    "duration_ms": 70115,
    "created_at": 1772067019,
    "next_flow_id": null
  }
]
```

## Data Fields Explanation

### Prompt and Response Fields:
- **`input_prompt`**: The prompt that was sent to the flow execution
- **`output_response`**: The response generated by the flow execution
- **`prompt`** (in iterations table): The prompt for a specific iteration
- **`response`** (in iterations table): The response for a specific iteration
- **`openhands_response`** (in iterations table): The OpenHands response for a specific iteration

### Metadata Fields:
- **`flow_id`**: Identifier of the flow that was executed
- **`conversation_id`**: Identifier of the conversation
- **`step_id`**: Identifier of the step within the flow
- **`status`**: Execution status (e.g., "completed", "failed")
- **`duration_ms`**: How long the flow run took in milliseconds
- **`created_at`**: Timestamp when the flow run was created
- **`next_flow_id`**: Next flow to execute (for flow chaining)

## Example: Extracting Prompts and Responses

### Using JavaScript/TypeScript:
```javascript
// Get all flow runs
const response = await fetch('https://deepseek-agent.alghamdimo89.workers.dev/api/flow-runs');
const flowRuns = await response.json();

// Extract prompts and responses
flowRuns.forEach(flowRun => {
  console.log(`Flow ID: ${flowRun.flow_id}`);
  console.log(`Prompt: ${flowRun.input_prompt}`);
  console.log(`Response: ${flowRun.output_response}`);
  console.log(`Status: ${flowRun.status}`);
  console.log(`Duration: ${flowRun.duration_ms}ms`);
  console.log('---');
});

// Get specific flow run
const flowRunId = 'flow_run_1772067089928_4t7ymzz5t';
const singleResponse = await fetch(`https://deepseek-agent.alghamdimo89.workers.dev/api/flow-runs/${flowRunId}`);
const flowRun = await singleResponse.json();
console.log(`Specific flow run prompt: ${flowRun.input_prompt}`);
console.log(`Specific flow run response: ${flowRun.output_response}`);
```

### Using Python:
```python
import requests

# Get all flow runs
response = requests.get('https://deepseek-agent.alghamdimo89.workers.dev/api/flow-runs')
flow_runs = response.json()

for flow_run in flow_runs:
    print(f"Flow ID: {flow_run['flow_id']}")
    print(f"Prompt: {flow_run['input_prompt']}")
    print(f"Response: {flow_run['output_response']}")
    print(f"Status: {flow_run['status']}")
    print(f"Duration: {flow_run['duration_ms']}ms")
    print("---")
```
